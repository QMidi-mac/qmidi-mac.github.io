QMidi: Ultimate MIDI and Karaoke Player

The premier multimedia karaoke player for macOS. Seamlessly organize and play MIDI, MP3 with lyrics, CDG, and movie files. Edit and sync text and chords effortlessly, with real-time pitch shifting, time-stretching, and full-screen display across monitors.

Universal Format Support

Handles any audio/video format via Core Audio or QuickTime, including MIDI 0/1, native FLAC, MP3 ID3 lyrics, CDG, and movie karaoke. Multi-page PDFs sync perfectly.

Precision Editing and Sync

Edit, synchronize, and merge external text, chords, LRC/LRC+, and ChordPro files. Export changes with time stretch, pitch/chord transpose for flawless performances.

Advanced Playback Control

Real-time pitch shifting, time-stretching, and full-screen karaoke or movies—even on secondary displays. Custom text formatting with backgrounds, plus MIDI mixer and GS effects.

Professional Library Management

Build music libraries and playlists. Convert text karaoke/CDG to movies. Remote control via MIDI or AppleScript. Supports Core MIDI devices, SoundFonts, and multiple encodings.

How It Works

1. Import and Organize

Drag in MIDI, MP3, CDG, movies, or PDFs. QMidi auto-detects lyrics, chords, and formats for instant library setup.

2. Edit and Sync

Fine-tune text, chords, or timings. Sync multi-page content or merge files with drag-and-drop precision.

3. Customize Playback

Adjust pitch, tempo, or chords in real-time. Apply effects, set custom backgrounds, and mirror to full-screen or external displays.

4. Perform and Export

Play via MIDI devices or remote control. Export edited tracks, LRC, or ChordPro for sharing.
